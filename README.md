# [Mobirise AI Website Builder](https://ai.mobirise.com/)

Mobirise is a free website builder. Describe your site in a prompt and Mobirise AI builds the first version, or start from a theme. Then change anything in the visual drag-and-drop editor or in chat with AI.

Mobirise runs in the browser and as a desktop app for Windows, Mac and Linux. Both are the same Mobirise with the same features. The desktop app also works offline; AI and publishing need an internet connection.

Mobirise is free for personal and commercial use. It is not open source: this repository holds the release notes, not the source code of the app.

Website: [mobirise.com](https://mobirise.com/) · Mobirise AI: [ai.mobirise.com](https://ai.mobirise.com/)

## What you can do

- **Create a site with AI.** Write what the site is about, and Mobirise AI makes the first version. Regenerate to get more variants.
- **Edit visually.** Drag blocks onto the page, change text in place, and set fonts and colors for the whole site at once.
- **Start from a theme.** Themes come with ready-made blocks: menus, headers, galleries, sliders, forms, pricing tables, maps and footers.
- **Publish where you want.** Upload to your own hosting over FTP, SFTP, FTPS or FTPES, publish to GitHub Pages or a free Mobirise subdomain, connect your own domain, or export the code to a folder.
- **Get mobile-friendly sites.** Pages are built on Bootstrap and adapt to phones, tablets and desktops.
- **Add more with extensions.** Code Editor for your own HTML and CSS, Form Builder, Popup Builder, PayPal Shopping Cart, Cookie Alert and others.
